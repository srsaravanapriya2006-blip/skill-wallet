# Project Demonstration Phase

## Project Title
Implement Client Script & UI Policy (Incident)

## Demonstration Overview

The project demonstration shows the implemented UI Policies and Client
Scripts on the ServiceNow Incident table.

The demonstration covers the main configured behaviors and validation
scenarios.

## Demonstration Includes

- High Impact condition and mandatory Assignment Group.
- Urgency behavior for High-impact Incidents.
- Automatic setting of Urgency when Impact is High.
- Validation that prevents saving when Assigned To is missing.
- Prevention of State changes through direct list editing.
- State update through the Incident form.
